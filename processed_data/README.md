# Generated data

This directory is populated when the pipeline runs. Generated Parquet outputs include:

- `nba_pbp_cleaned.parquet`
- `events_clean.parquet`
- `clutch_events.parquet`
- `player_clutch_stats.parquet`
- `clutch_player_rankings.parquet`
- `top20_clutch_scorers.parquet`
- `top20_clutch_fg_pct.parquet`
- `high_usage_low_eff.parquet`
- `low_usage_high_eff.parquet`
- `era_bias_summary.parquet`

The data files themselves are excluded from version control because they can be regenerated from the Kaggle source.
